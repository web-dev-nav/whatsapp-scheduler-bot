WhatsApp Patrol Automation Plan

Prepared for Navjot Singh on August 6, 2026

Main goal: start a shift, drive patrol rounds, keep the iPhone screen off, and have the patrol completion/checkpoint message sent automatically to the WhatsApp group.

1. Recommended Practical Setup

The best setup is to keep each tool responsible for one clear job:

Part Job
iPhone Shortcuts Detect arrival at a patrol location in the background.
n8n Community Edition Receive the iPhone trigger, log it, optionally filter duplicates, and call the WhatsApp scheduler app.
WhatsApp Scheduler App Keep the WhatsApp Web session connected and send the message to the configured WhatsApp group.
Tailscale Funnel Expose the n8n webhook over HTTPS so the iPhone can call it from anywhere.
iPhone location automation -> Tailscale Funnel -> n8n webhook -> local scheduler app -> WhatsApp group

3. Why Browser Patrol Mode Is Not Enough

The browser patrol page in this repo is useful for setup and testing:

  • It shows a map.
  • It lets you add checkpoints.
  • It lets you set checkpoint radius.
  • It can trigger messages while the page is open.

Limitation: browser GPS is not reliable when the iPhone screen is off. iOS can pause Safari JavaScript and location tracking in the background.

For screen-off patrol automation, iPhone Shortcuts location automation is the better first option.

4. iPhone Shortcuts Limitation

iPhone Shortcuts can run background arrival automations, but Apple does not always let you choose an exact radius. The location trigger is approximate.

Practical expectations:

  • Use real checkpoint areas, gates, corners, or landmarks.
  • Expect a rough trigger zone, often around 100 meters or more.
  • Drive away and re-enter the area when testing.
  • Turn off Low Power Mode for best reliability.
  • Use "Run Immediately" where iOS offers it.

6. iPhone Shortcut Setup

  1. Open the Shortcuts app on iPhone.
  2. Create a new shortcut.
  3. Add action: Get Contents of URL.
  4. URL: https://hp-server.tailed5092.ts.net/webhook/patrol-test
  5. Method: POST.
  6. Request Body: JSON.
  7. Add fields: source, guard, checkpointName.
  8. Run manually first and confirm it appears in n8n Executions.

7. iPhone Location Automation Setup

  1. Open Shortcuts.
  2. Tap Automation.
  3. Create a new automation.
  4. Select Arrive.
  5. Pick the checkpoint location.
  6. Choose Run Immediately if available.
  7. Add Get Contents of URL.
  8. Use the same n8n production webhook URL.
  9. Send JSON with the checkpoint name for that location.
  10. Create one automation per checkpoint.

8. Next n8n Workflow: Connect To WhatsApp Scheduler

Once the scheduler app runs on the same home server as n8n, add an HTTP Request node after the Webhook node.

Webhook -> HTTP Request -> Respond to Webhook

HTTP Request node settings:

Method: POST
URL: http://127.0.0.1:3000/api/patrol/trigger?account=main

If a patrol token is enabled:

URL: http://127.0.0.1:3000/api/patrol/trigger?account=main&token=YOUR_TOKEN

JSON body:

{
  "source": "n8n-iphone-shortcuts",
  "checkpointName": "{{ $json.body.checkpointName }}"
}

9. Home Server Requirements

  • n8n running and reachable through Tailscale Funnel.
  • WhatsApp Scheduler app running locally on the home server at port 3000.
  • Home server stays awake 24/7.
  • WhatsApp session is linked and ready.
  • The target WhatsApp group is selected in the scheduler app.

10. Security Plan

Before using this with teammates, add access control:

  • Admin password for the scheduler UI.
  • Per-guard account tokens.
  • Per-guard webhook URLs or guard IDs.
  • n8n duplicate protection to stop repeated messages.
  • Keep the scheduler app private if possible; expose n8n only.

11. Team/Guard Plan

The scheduler app can support multiple WhatsApp accounts. Each guard can have:

  • Separate WhatsApp QR session.
  • Separate target group/chat.
  • Separate message.
  • Separate checkpoint names.
  • Separate webhook token.

Recommended guard payload from iPhone to n8n:

{
  "source": "iphone-shortcuts",
  "guard": "navjot",
  "checkpointName": "North checkpoint",
  "token": "guard-secret"
}
